# Upstream attribution

This directory contains the `modern-web-guidance` skill entry from [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance), installed for OpenCode with the official Vercel Skills CLI. The upstream source and content hash are recorded in the repository's `skills-lock.json`.

## Usage and telemetry

The upstream CLI reports anonymous usage data, including guide IDs and search queries generated by the agent. Set `DISABLE_TELEMETRY=1` for CLI invocations to opt out. It requires Node.js 22 or newer. Fetching or updating it with `npx` requires network access; upstream documents local search and retrieval once the package is available. This skill-only setup does not add it as a project dependency. The lockfile records the installed skill source, not a pinned version of the CLI invoked with `@latest`.
