# Earth Analog Explorer

NASA Space Apps 2026 entry for the challenge *Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars*.

The app ranks Earth test sites by how closely their terrain matches a target on the Moon (lunar south pole base areas) or on Mars (Jezero crater). For Moon targets it also shows how far each site's lighting is from polar lighting, and warns when the two disagree.
